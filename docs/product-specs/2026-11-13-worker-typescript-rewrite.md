# worker TypeScript 重写规格

状态：待实施。现有生产版本仍以 Python worker 运行，并支持原有模型选项；本规格定义重写后的目标行为。

## 目标和范围

将 Locus 自有 `worker/` 的 Python 运行期替换为 TypeScript。迁移覆盖媒体处理、ASR、模型管理、网页笔记保存、任务存储、工作间工具、LLM 连接测试和数据存储校验。除本规格明确调整的模型选项外，产品现有功能、用户数据和安全边界持续有效。

- 视频、音频和网页来源继续使用现有流程；已保存的媒体任务和网页笔记可读取、编辑和继续处理，历史、合集及用户设置保持可用。
- 工作间的要点总结、文字稿解剖、启发灵感、生成文字稿、文字稿整理及自动标题继续支持现有入口、产物、确认、计费、取消与失败行为。托管模型和 BYOK 按现有规则运行；草稿检索保留现有服务端 anysearch 行为。
- ASR 仅提供当前默认的 `iic/SenseVoiceSmall-onnx`，设置、模型准备和新任务统一使用此模型；不再提供 PyTorch 模型 `iic/SenseVoiceSmall` 的选择和运行时组件下载。ASR 内部保留清晰的模型适配接口，后续可在不重写任务流程的前提下接入其他模型。
- 升级时，原设置选为 `iic/SenseVoiceSmall` 的用户一次性迁移到 `iic/SenseVoiceSmall-onnx`，并在设置中明确提示模型已变更；原本选用 ONNX 的用户继续使用当前设置。其他设置不变，未知模型设置须明确报错，不得当作旧 PyTorch 设置静默迁移。
- 已有 PyTorch 模型文件、运行组件和原 ONNX 缓存保留在用户数据目录，不自动删除；历史文字稿、任务及其原始模型标识继续可读。旧模型文件是否可参与后续数据位置迁移和恢复，按数据完整性验证，不能要求新 worker 执行旧 PyTorch 组件。
- 核心 ASR 模型继续在用户提交已验证任务且所选模型缺失时按需下载；启动时不自动下载。下载进度、取消、完整性校验、离线及失败行为保持可见。安装包不内置 ASR 权重、LLM key、云端模型或用户私有配置。
- 已有 ONNX 缓存能否直接复用由文件格式和识别引擎兼容性决定；不兼容时保留原有缓存，提示需要下载模型，并在用户提交已验证任务后按需准备。使用同源的其他 ONNX 导出文件时，须核实来源、许可、完整性与质量，不能声称文件相同或把旧缓存标记为可直接使用。

## 进程、数据与安全

- 继续由 Rust 监督 worker，保留固定绝对超时、已验证进度的空闲超时、取消及进程树终止。受限 stdin、结构化结果、进度事件和错误处理继续遵守现有边界；模型可选值收窄涉及 `contracts/desktop-worker-contract.json`、前端、Rust 与 worker 的一致更新和版本兼容验证。
- 任务清单、文字稿及 AI 产物沿用既有 schema、来源核验、原子写入、多文件事务恢复和数据位置许可；旧任务兼容必须使用真实旧任务验证。
- 视频、音频、文字稿、模型缓存与本地历史默认留在本机；账号服务不接收这些内容或 cookie。公开或已授权的来源、模型下载、用户确认的 LLM 调用和现有草稿检索继续遵守各自的网络与隐私边界。
- 发行包内不再包含供自有 worker 使用的 Python 运行时。用户允许官方独立 yt-dlp 程序内置 Python，作为唯一第三方例外；继续支持现有公开或已授权来源及下载行为。ffmpeg 和 ffprobe 继续提供现有媒体处理行为，音频归一化参数保持 `-vn -ac 1 -ar 16000 -c:a pcm_s16le`。第三方组件分发前核实许可、来源、完整性与三平台运行。

## ASR 与验收

现有默认路径使用 `funasr_onnx` 和 FSMN VAD；可行性测量使用 `sherpa-onnx-node`、同源但文件不同的 SenseVoice 导出模型和 Silero VAD。以现有 ONNX 生产路径为唯一 ASR 质量与性能基线，实验结果需要通过正式验收。接口职责和适配边界见 `docs/design-docs/2026-11-13-typescript-worker-asr-boundary.md`。

新实现必须验证长语音分块、句首丢词、跨停顿分段、时间戳、重复文本、无语音和纯音乐等情况。识别质量与性能使用同一固定语料、同一硬件和可复现的 Python ONNX 基线比较；验收全程自动化，自动参考文本须独立于候选生成，其结果是质量代理指标。无语音时沿用 `ASR_EMPTY_TRANSCRIPT` 失败语义，不写入虚构文字。具体门槛和执行方式以执行计划为准。

发布前验证各受支持平台的打包应用、原生依赖、下载、旧数据、任务取消、异常恢复和工作间。安装包体积按实际三平台构建与现有版本对比记录，不能预先假定完全相等。
